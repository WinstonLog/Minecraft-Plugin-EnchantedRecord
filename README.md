**EnchantedRecord** — уникальный плагин для Minecraft, позволяющий переносить зачарования с предметов на книги через точильный камень с полным контролем над выбором.

## 📋 Быстрый старт

### Установка за 3 шага:
1. **Скачать** → Получите JAR файл плагина

2. **Установить** → Поместите в папку `plugins/`
3. **Настроить** → Настройте под свой сервер

### Основные команды:

/enchantedrecord help - Помощь по командам
/enchantedrecord reload - Перезагрузить конфигурацию
/enchantedrecord version - Информация о плагине


## 🎯 Ключевые особенности

**📖 Выборочный перенос зачарований**
Интерактивное меню — выбирайте конкретное зачарование из нескольких
Сохранение ценных чар — перед ремонтом или перезачарованием
Создание библиотек — коллекции редких и дорогих зачарований

## 🛡️ Защита и баланс
Кулдаун системы — предотвращение злоупотреблений
Черные списки — миров и предметов
Настройка стоимости — книги потребляются по выбору

## 🚀 Установка

### Требования:
- ✅ **Minecraft**: 1.16.x и выше
- ✅ **Сервер**: Spigot, Paper, Bukkit
- ✅ **Java**: 11 или выше
- ✅ **Плагин**: LuckPerms (рекомендуется)

### Шаг 1: Скачать плагин
```bash
# Способ 1: Через релизы GitHub
[https://github.com/Day2S/ProfessionMaster/releases](https://github.com/day2s/EnchantedRecord/releases)

# Способ 2: Через менеджера плагинов
# (укажите ваш способ распространения)
```

### Шаг 2: Установить на сервер
```bash
1. Остановите сервер
2. Поместите EnchantedRecord.jar в папку plugins/
3. Запустите сервер
4. Плагин создаст конфигурационные файлы автоматически
```

### Шаг 3: Базовая настройка
```bash
# Основные настройки
language: "ru"  # Язык плагина (ru/en)
require-book: true  # Требовать книгу в инвентаре
consume-book: true  # Потреблять книгу при создании
```
